Why ngu-dropdown

An honest scrollbar
It is sized to the server's total from the first response. Dragging it to row 25,000 asks for that one page, not the 499 before it.
Bounded memory
At most twelve pages are kept and about fifteen rows are in the DOM, however long the list and however far people scroll.
No stale answers
A new search, filter or sort cancels requests in flight and drops late answers, so the list never shows rows for a query that has changed.
Names, not ids
lookupFn names the ids an edit form loads, without opening the list. People see "Maple Agro & Co", not 4821.
Every form API
Signal Forms [formField], reactive forms, ngModel or a plain [(value)]. Disabled, required and invalid states follow the form.
Accessible
The ARIA combobox pattern, full keyboard support, each virtual row's place in the whole list, forced colors and reduced motion. The site is checked with axe.
